# beOpenDigital — `.github`

Repositório de arquivos padrão de comunidade (*community health files*), perfil público da organização, modelos de issues/pull requests e templates de workflows da **OpenDigital** no GitHub.

## Estrutura

| Caminho | Finalidade |
| --- | --- |
| [`profile/README.md`](profile/README.md) | Perfil público exibido em [github.com/beOpenDigital](https://github.com/beOpenDigital) |
| [`SECURITY.md`](SECURITY.md) | Política padrão de reporte responsável de vulnerabilidades |
| [`CODE_OF_CONDUCT.md`](CODE_OF_CONDUCT.md) | Código de conduta da comunidade (Contributor Covenant 2.1) |
| [`CONTRIBUTING.md`](CONTRIBUTING.md) | Diretrizes gerais de contribuição |
| [`SUPPORT.md`](SUPPORT.md) | Canais oficiais de suporte e contato |
| [`.github/ISSUE_TEMPLATE/`](.github/ISSUE_TEMPLATE/) | Formulários padrão para relato de bugs e propostas |
| [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md) | Modelo padrão de Pull Request |
| [`workflow-templates/`](workflow-templates/) | Modelos iniciais de GitHub Actions disponíveis para novos repositórios |
| [`.github/workflows/`](.github/workflows/) | Workflows reutilizáveis e validação deste repositório |

> Arquivos internos, mapeamento de repositórios privados e padrões operacionais da equipe ficam em `beOpenDigital/.github-private`.
